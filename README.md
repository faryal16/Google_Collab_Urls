# 🎮 Mini Games Collection  

Welcome to the **Mini Games Collection**! 🚀  
This folder contains a variety of fun and interactive Python games, designed to enhance your programming skills while having fun. Each game focuses on different programming concepts, including user interaction, loops, conditionals, and more.  

---

## 📌 Games Included  

- 🔹 **Mad Libs** – A fun word game where you fill in the blanks to create a hilarious story.  
- 🔹 **Guess the Number** – The player tries to guess a randomly chosen number.  
- 🔹 **Computer Guesses User's Number** – The computer attempts to guess the user's chosen number.  
- 🔹 **Rock-Paper-Scissors** – The classic hand game played against the computer.  
- 🔹 **Hangman** – Guess the word before you run out of attempts!  
- 🔹 **Countdown Timer** – A timer that counts down and notifies the user when time's up.  
- 🔹 **Password Generator** – Generates strong and secure passwords.  
- 🔹 **BMI Calculator (Streamlit)** – Calculate your Body Mass Index using a Streamlit app.  
- 🔹 **Weather App (Streamlit)** – Get real-time weather updates using an API.
